# 星链 ERP 管理端设计系统

视觉基准：`design/order-workbench-concept.png`。

## Tokens

- 页面背景：`#f5f7fa`
- 面板背景：`#ffffff`
- 侧边栏：`#14233b`，激活项 `#23456e`
- 主色：`#2563eb`
- 主文字：`#1f2937`，次级文字：`#64748b`
- 边框：`#dfe5ec`
- 成功：`#16a34a`，警告：`#d97706`，异常：`#dc2626`
- 面板圆角：4px；控件圆角：4px；标签圆角：3px
- 控件高度：34px；表格行高：58px
- 侧边栏宽度：164px；订单详情抽屉：440px

## Typography

- 字体：Inter、PingFang SC、Microsoft YaHei、sans-serif
- 页面标题：22px / 600
- 区块标题：15px / 600
- 正文与表格：13px / 400
- 辅助信息：12px / 400

## Component Families

- 导航：深色侧边栏、线性图标、44px 行高、单一蓝色激活底。
- 筛选：一行平台分段控件加两行紧凑表单，不使用卡片网格。
- 表格：细边框、浅灰表头、状态色只用于小标签，选中行浅蓝。
- 抽屉：固定右侧、分区细横线、订单状态在首屏可见、内容独立滚动。
- 异常队列：复用订单表格，异常码使用红色描边标签，不增加统计卡片。
